# Catálogo Federado DataMesh Bolivia

Bienvenido al Registro Central (Catálogo) de la red DataMesh. Este repositorio actúa como el índice principal de descubrimiento para que investigadores, analistas y Agentes de IA puedan encontrar conjuntos de datos abiertos, descentralizados y verificables.

## ¿Cómo agregar tu Nodo / Institución a la red?

Para unirte al ecosistema DataMesh, tu institución debe:
1. Haber publicado un nodo válido (ODKF + DataPackage) siguiendo las especificaciones en `docs/specificacion_knowledge.md`.
2. Crear un **Pull Request** hacia este repositorio agregando tu enlace en el archivo `catalog.md`.

*(Para propósitos de este ejemplo, puedes revisar la carpeta `nodes/` para ver ejemplos de diferentes arquitecturas de nodos: simulados locales, en Kaggle y en GitHub Releases).*
