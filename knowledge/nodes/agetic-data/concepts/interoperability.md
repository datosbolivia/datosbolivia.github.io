# Interoperabilidad

La **interoperabilidad** es la capacidad de dos o más sistemas o componentes para intercambiar información y utilizar la información intercambiada.

En el contexto del gobierno (AGETIC), se refiere a la plataforma de interoperabilidad del Estado, que permite el intercambio seguro de datos entre diferentes entidades públicas para simplificar trámites gubernamentales.
